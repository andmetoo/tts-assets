# tts-assets

Speech model archives that the Koona apps download. This repository holds no code: the files are attached to
its releases, and the apps fetch them from there when their first address does not answer.

## supertonic-3 (release v1.0.0)

`supertonic-3-v1.tar.zst` is the speech model **Supertonic 3** by Supertone, packed unchanged for Koona Books'
"Koona voice", which reads books aloud on the reader's own computer.

- Size: 370,808,268 bytes
- SHA-256: `6757912bdb8bc23fc19891814a4f18f5e2c334c1d8640cbc581eb9003dd214cc`
